# 10. EXTROVELA — Memory Calendar & Open-World Life Map

## 1. Memory Calendar Journal
- Visual month/week grid displaying completed real-life story cards.
- Filterable by tags: First-Time, Sunsets, Cafés, Solo, Social.
- Card contents: Photo memory, rating, reflection note, voice note audio duration.

## 2. Open-World Video Game Life Map (Fog of War)
- Styled like an open-world exploration game (e.g. Skyrim / Zelda map reveal).
- Dark ambient map tiles with dark fog over unvisited districts.
- Logging a quest unlocks that geographic area and drops a glowing photo memory pin.
- Exploration Percentage Counter: e.g. `32% Kathmandu Unlocked`.
