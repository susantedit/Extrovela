# 11. EXTROVELA — Routine Breaker & Recovery Engine

## 1. Routine Pattern Breaker Logic
- **Indoor Loop Breaker**: If user completes 3 consecutive indoor quests, the engine automatically prioritizes outdoor/nature options by +40%.
- **Exclusive Solo Breaker**: If user completes 5 consecutive solo quests, gently introduces low-pressure social quests (e.g. compliment 5 strangers, call an old friend).
- **Familiar Path Breaker**: Recommends exploring unseen alleys or riding a new bus route if user stays in familiar zones.

## 2. Low-Energy Recovery Quests
- For days when the user feels drained or low energy: 15-minute phone-free cloud watching, listening to rain, or cozy teahouse reading.
