# EXTROVELA — Calendar Journal & Life Map Documentation

## 1. Calendar Journal
- **Visual Memory Grid**: Displays logged quests by completion date.
- **Card Contents**: Quest photo snapshot, reflection note, star rating, geotag place name, and first-time tag.
- **Filtering**: By First-Time experiences, Sunsets, Moods, and Locations.

## 2. Interactive Open-World Life Map (Fog of War)
- **Concept**: Open-world video game fog mechanics for real-world living.
- **Fog of War**: Unvisited city areas remain in dark fog.
- **Revealed Memory Pins**: Every completed quest drops an interactive glowing pin on the map.
- **Exploration Counter**: Displays city unlocked percentage (e.g. 32% Kathmandu Unlocked).
