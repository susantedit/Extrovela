# EXTROVELA — Android & iOS Cross-Native Architecture

## Native Mobile Capabilities & Integration
- **Framework**: Capacitor / React Native Cross-Platform Hybrid Container
- **Platforms Supported**: iOS 14+ & Android 8.0+ (API 26+)
- **Device Capabilities Integrated**:
  1. **Geolocation API**: Geotagging memory snapshots and uncovering fog-of-war areas on the Life Map.
  2. **Camera & Photos**: Capturing real-world photos for journal memories.
  3. **Microphone / Audio**: Recording 15-second voice reflections.
  4. **Haptic Feedback**: Tactile vibration feedback on accepting quests and completing experiences.
  5. **Local Storage & Offline Mode**: Full offline mode so quests can be completed in remote mountain viewpoints or dead zones.
