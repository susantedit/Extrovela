# 05. EXTROVELA — Personalization & Long-Term Memory System

## 1. Interaction & Feedback Learning
- **Post-Quest Rating**: 1 to 5 star rating informs future engine weighting. High ratings boost similar quest categories. Low ratings reduce category frequency.
- **Reflection Analysis**: Short reflection notes parse keywords (e.g., "peaceful", "crowded", "view") to refine mood matching.
- **First-Time Experience Tracker**: Keeps a dedicated ledger of unlocked milestone experiences.

## 2. Long-Term Experience Memory
- Persisted in local storage / database.
- Powers monthly recap summaries ("Your August").
- Powers Open-World Fog-of-War Map pins.
