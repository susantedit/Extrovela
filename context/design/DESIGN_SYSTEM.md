# EXTROVELA — Design System & UI/UX Specifications

## Typography System
- **Instagram-Inspired Typography Aesthetic**: Clean, geometric, high-contrast display headlines combined with ultra-readable body font.
- **Display Headlines Font**: `Outfit` (Bold / ExtraBold / Black, tight letter-spacing `-0.03em`)
- **Body & Controls Font**: `Plus Jakarta Sans` (Medium / SemiBold, letter-spacing `-0.015em`)
- **Monospace Metrics**: `JetBrains Mono` for timers, coordinates, and percentages.

## Color Palette & Visual Style
- **Background**: Deep Dark Ambient (`#08090D`)
- **Card Background**: Blur Glassmorphism (`rgba(22, 26, 38, 0.75)` with `backdrop-filter: blur(20px)`)
- **Gradients & Neons**: Warm Golden Sunset (`linear-gradient(135deg, #F59E0B 0%, #F43F5E 100%)`)
- **Micro-Animations**: Smooth scale transitions, pulsing glow rings for phone-free mode, confetti celebrations on memory capture.
